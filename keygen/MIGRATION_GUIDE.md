# 密码机主机迁移手册

本文档用于把密码机从旧主机快速迁移到新主机。

推荐优先使用前端迁移包方式，因为不需要手工进入容器，也不依赖 SQLite 文件路径。

## 推荐方案

### 旧主机导出

1. 启动旧主机上的密码机。
2. 登录页面。
3. 点击右上角“迁移数据”。
4. 点击“下载迁移包”。
5. 保存导出的 JSON 文件。

迁移包会包含：

- 产品数据
- 客户数据
- 授权记录
- 手动补时 / 扣时记录
- 导出时间、导出人、构建信息、数量摘要

### 新主机导入

1. 在新主机部署并启动密码机。
2. 登录页面。
3. 点击右上角“迁移数据”。
4. 选择旧主机导出的 JSON 迁移包。
5. 点击“上传并恢复数据”。
6. 等待页面提示恢复成功。

## 重要说明

1. 导入是覆盖式恢复，会先清空当前数据，再恢复迁移包中的数据。
2. 如果新主机里已经有测试数据，导入后这些数据会被覆盖。
3. 建议在新主机导入前，也先导出一份当前迁移包留档。
4. 迁移完成后，建议检查产品数、客户数、授权记录数是否与旧主机一致。

## 兜底方案

如果前端迁移包暂时不可用，可以直接迁移运行数据目录。

关键位置：

- 运行目录数据：soft/keygen/data
- 运行目录备份：soft/keygen/backups
- 容器内默认数据库：/app/data/keygen.db

建议步骤：

1. 在旧主机先执行一次同步命令，自动生成最新备份。
2. 备份 soft/keygen/data 和 soft/keygen/backups。
3. 在新主机部署好密码机后，覆盖恢复这两个目录。
4. 重新启动运行版容器。

相关命令：

```bash
bash soft/keygen/sync_keygen_runtime.sh
```

## 建议核对项

迁移完成后，至少核对以下内容：

1. 产品列表是否完整。
2. 客户数量是否正确。
3. 授权记录总数是否一致。
4. 客户下已购产品和剩余时长是否正常。
5. 手动补时 / 扣时记录是否还在。

## 适用范围

本文档同时适用于：

1. 源码版迁移到源码版。
2. 运行版迁移到运行版。
3. 源码版迁移到运行版。
4. 同一台机器重装系统后的数据恢复。
