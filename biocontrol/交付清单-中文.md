# BioControl 旧 Web 交付清单

这份交付目录仅保留作历史参考，当前桌面主线请优先查看 source/biocontrol-wails-source。

当前交付目录说明：

- linux：Linux 标准版无源码交付目录
- linux-no-logo：Linux 无 Logo 版无源码交付目录
- mac：macOS 无源码交付目录
- win：Windows 无源码交付目录
- packages：可直接分发的压缩包目录

本次生成的压缩包：

1. biocontrol-linux-20260424.tar.gz
2. biocontrol-linux-no-logo-20260424.tar.gz
3. biocontrol-mac-20260424.tar.gz
4. biocontrol-win-20260424.zip

分发建议：

1. Linux 客户默认发送 biocontrol-linux-20260424.tar.gz
2. 需要隐藏 Logo 时发送 biocontrol-linux-no-logo-20260424.tar.gz
3. macOS 客户发送 biocontrol-mac-20260424.tar.gz
4. Windows 客户发送 biocontrol-win-20260424.zip

授权说明：

1. 客户部署后先进入试用期
2. 系统激活页会显示服务器物理地址
3. 管理员使用 soft/keygen 生成许可证
4. 客户粘贴许可证完成激活

一键安装入口：

1. Linux/macOS 包：解压后进入对应目录执行 bash install.sh
2. Windows 包：解压后进入对应目录执行 powershell -ExecutionPolicy Bypass -File .\install.ps1
